# Shchenin-shchenin · שכנים־שכנים
An interactive web prototype for managing residential communities in everyday life and emergencies, including status reports, help requests, shared resources, tasks, and real-time building updates.

אבטיפוס אינטראקטיבי לאפליקציית ניהול קהילה בבניין מגורים — **בשגרה ובחירום**.

> "הבניין שלכם, קהילה אחת" — בשגרה עוזרים. בחירום יודעים מה קורה.

## מה יש כאן

`index.html` — אבטיפוס Web מלא בקובץ אחד, ללא תלויות חיצוניות. פותחים בדפדפן וזה עובד.

- עברית מלאה, RTL, Mobile First (עד 430px; בדסקטופ מוצג במסגרת מכשיר)
- ללא ספריות, ללא CDN, ללא בנייה — HTML + CSS + Vanilla JS

## הפיצ'רים — כולם עובדים מקצה לקצה

**שגרה**
- אונבורדינג 8 שלבים: טלפון → קוד → בניין → דירה → פרטים → יכולות → ציוד → פרטיות
- מסך בית: הודעת ועד, פעולות מהירות, בדיקת מוכנות אישית, כניסה לחירום
- קהילה: פרסום, סינון לפי קטגוריה, תגובות־לפעולה — שכנים עונים לכם בזמן אמת
- משאבים: השאלת ציוד במחזור מלא (בקשה → אישור → איסוף → החזרה)
- שכנים ומיומנויות: חיפוש מי יודע מה בבניין + פנייה אישית שמקבלת מענה
- דיווח תקלה עם מעקב סטטוס: נשלח לוועד → בטיפול → טופל
- פרופיל: יכולות, בקרות פרטיות עם הסבר לכל שדה
- ניהול הבניין (תצוגת ועד): Dashboard, דירות ודיירים, טיפול בתקלות, הודעות רשמיות, היסטוריית אירועים

**חירום** — הממשק כולו מתחלף (באנר + ניווט ייעודי: מצב · דיווח · בקשות · משימות · עדכונים)
- דיווח בשלושה כפתורים: בסדר / צריכים עזרה / מצב חירום
- זרימת בקשת עזרה בשלושה שלבים (סוג → דחיפות → פרטים) עם סטטוס חי
- מסך מצוקה שמפנה קודם ל־100/101/102 ומדווח לבניין במקביל
- מפת בניין חיה לפי סטטוס דירות + פרטי דירה בלחיצה
- "כוחות זמינים": מי מיומן ואיזה ציוד קיים בין המדווחים "בסדר"
- הקצאת מתנדבים לפי התאמה ונימוק (רכז) או התנדבות עצמית (דייר)
- משימות למתנדב: יוצאים לדרך → טופל, עדכונים רשמיים, סיום אירוע וסיכום עם המלצות

**מרכז ההדגמות** — שלושה תסריטים מודרכים במסך הפתיחה ובפרופיל:
1. **יום בחיי הבניין** — שגרה חיה: פרסומים נכנסים, שכנים מגיבים, השאלות מאושרות
2. **תרגיל חירום מלא** — דיירים מדווחים בהדרגה, בקשת עזרה נכנסת, ואתם מקבלים משימה
3. **אירוע אמת** — אותו תרחיש בממשק אמת

**דף תדמית** — בעיה → פתרון → איך זה עובד → CTA לפיילוט עם טופס עובד ("על המוצר" במסך הפתיחה).

## הפעלה

```
open index.html
```

או כל שרת סטטי. אין צורך בהתקנות.

## מסלול הדגמה מומלץ (למשקיעים)

1. מסך פתיחה → "▶ מרכז ההדגמות" → **יום בחיי הבניין** — לפרסם, להגיב, להשאיל ציוד, לדווח תקלה
2. פרופיל → הפעלת **תצוגת רכז** → "ניהול הבניין" — לטפל בתקלה ולפרסם הודעת ועד
3. מרכז ההדגמות → **תרגיל חירום מלא** — לדווח "בסדר", לצפות במפה מתמלאת, לקחת משימה, לסיים אירוע ולקבל סיכום
4. מסך פתיחה → "על המוצר" — דף התדמית וטופס הפיילוט

## בדיקות

`node --check` על הסקריפט + שני טסטים אוטומטיים ב־Playwright שמריצים את כל הפיצ'רים מקצה לקצה (מעל 100 צעדים) — כולם עוברים ללא שגיאות קונסול.
