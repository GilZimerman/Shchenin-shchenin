# Shchenin-shchenin · שכנים־שכנים
An interactive web prototype for managing residential communities in everyday life and emergencies, including status reports, help requests, shared resources, tasks, and real-time building updates.

אבטיפוס אינטראקטיבי לאפליקציית ניהול קהילה בבניין מגורים — **בשגרה ובחירום**.

> "הבניין שלכם, קהילה אחת" — בשגרה עוזרים. בחירום יודעים מה קורה.

## מה יש כאן

`index.html` — אבטיפוס Web מלא בקובץ אחד, ללא תלויות חיצוניות. פותחים בדפדפן וזה עובד.

- עברית מלאה, RTL, Mobile First (עד 430px; בדסקטופ מוצג במסגרת מכשיר)
- ללא ספריות, ללא CDN, ללא בנייה — HTML + CSS + Vanilla JS

## התרחישים באבטיפוס

**שגרה** — הצטרפות לבניין (אונבורדינג 8 שלבים), מסך בית עם הודעת ועד ופעולות מהירות, פיד קהילה (פרסום, סינון, "אני יכול לעזור"), משאבי בניין עם השאלת ציוד, בדיקת מוכנות אישית, פרופיל עם בקרות פרטיות.

**חירום** — הפעלת אירוע (אמת/תרגיל), הממשק כולו מתחלף: באנר, ניווט ייעודי (מצב · דיווח · בקשות · משימות · עדכונים). דיווח בשלושה כפתורים (בסדר / צריכים עזרה / מצב חירום), זרימת בקשת עזרה בשלושה שלבים עם סטטוס חי, מפת בניין לפי סטטוס דירות, הקצאת מתנדבים לפי התאמה (תצוגת רכז), משימות למתנדב, עדכונים רשמיים, סיום אירוע וסיכום עם המלצות.

**סימולציה חיה** — עם הפעלת תרגיל, הבניין "מתעורר": דיירים מדווחים, בקשת עזרה נכנסת, והמשתמש מקבל משימת בדיקה של דירה שלא דיווחה.

## הפעלה

```
open index.html
```

או כל שרת סטטי. אין צורך בהתקנות.

## מסלול הדגמה מומלץ

1. במסך הפתיחה — "דילוג לסיור במצב הדגמה" (או לעבור את ההצטרפות המלאה)
2. לסייר בבית, בקהילה ובמשאבים
3. בבית — "מצב חירום" → "הפעלת תרגיל מוכנות"
4. לדווח "אנחנו בסדר" ולצפות במפת הבניין מתמלאת
5. במסך הבקשות — לקחת את הבקשה של רחל ("אני אטפל בזה") ולסגור אותה במשימות
6. במסך המצב — להפעיל תצוגת רכז ולסיים את האירוע → סיכום
