# 🚗 טריוויה בדרכים — משחק טריוויה זוגי לנסיעה

משחק טריוויה זוגי, תחרותי ומצחיק, שנבנה למשחק קולי בזמן נסיעה — עם **מאגר שאלות אינסופי מבוסס Claude AI** ומאגר מובנה לגיבוי.

## איך משחקים

1. פותחים את `index.html` בדפדפן (בטלפון או במחשב) — אין צורך בשרת.
2. ממלאים את פרטי ההיכרות (שמות, מי נוהג, נושאים, רמת קושי, שאלות אינטימיות).
3. בוחרים משחקון — ומתחילים!

מי שלא נוהג/ת מתפעל/ת את המסך. יש כפתור 🔊 להקראת שאלות בקול (עברית) כדי שהעיניים יישארו על הכביש.

## המשחקונים

| משחקון | איך זה עובד |
|---|---|
| 🥊 ראש בראש | כל אחד בתורו — תשובה נכונה שווה נקודה |
| 📏 הכי קרוב מנצח | שאלות אומדן מספריות — הקרוב יותר לוקח |
| ⚖️ נכון או לא נכון | עובדות מפתיעות — אמת או פייק? |
| 🕵️ שלושה רמזים | רמז 1 = 3 נק', רמז 2 = 2, רמז 3 = 1 |
| 💘 אני יודע/ת מה תבחר/י | מנחשים במה בן/בת הזוג יבחרו |
| 🧠 מי מכיר את מי? | שאלות אישיות — מי מכיר טוב יותר? |
| 🔥 חם, חם יותר | שאלות זוגיות אינטימיות (רק אם הופעל, אפשר תמיד "עוברים") |

כל סבב = 5 שאלות. תיקו? שאלת שובר שוויון. בסוף כל סבב — פרס או משימה אקראית 🎁

## מאגר שאלות אינסופי (Claude AI)

בהגדרות (⚙️) אפשר להדביק מפתח API של [Anthropic](https://platform.claude.com/). כשהמפתח קיים:

- Claude יוצר **שאלות חדשות בכל סבב**, מותאמות לנושאים שאתם אוהבים ולרמת הקושי.
- המשחק זוכר אילו שאלות כבר נשאלו ומבקש מ-Claude לא לחזור עליהן.
- שאלות אינטימיות נוצרות ברמת הנועזות שבחרתם בלבד.

המפתח נשמר **רק בדפדפן שלכם** (localStorage) ונשלח ישירות ל-API של Anthropic. מומלץ להשתמש במפתח ייעודי עם מגבלת תקציב.

בלי מפתח — המשחק עובד עם מאגר מובנה של ‎90+‎ שאלות בעברית.

## בטיחות לפני הכול 🛣️

- הנהג/ת לא צריך/ה לגעת במסך — רק לדבר.
- אין משימות פיזיות בזמן נהיגה.
- אפשר לומר "עוברים" על כל שאלה, בלי לאבד נקודות.
