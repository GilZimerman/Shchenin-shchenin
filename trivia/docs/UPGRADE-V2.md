# שדרוג v2 — משחק חכם, אישי ומתפתח

## ארכיטקטורה: הפרדת שכבות

```
index.html            ממשק המשתמש (מסכים, דיאלוגים)
css/style.css         עיצוב (כהה, RTL, Mobile-First, ניגודיות גבוהה)
js/questions.js       מאגר התוכן המובנה (92 שאלות + פרסים + שוברי שוויון)
js/templates.js       שכבת השפה: T() + משתני שמות + 36 קטעי מעבר
js/learning.js        מנוע הלמידה (Learn) — פרופיל דינמי לכל משתתף
js/engine.js          מנוע התוכן (Engine) — בחירה, דדופ, תור מקומי, מצבים
js/app.js             מנוע המשחק + שירותי קול + שכבת פרטיות + Claude API
```

כל שכבה מדברת עם השכנות שלה דרך API צר (`Learn.*`, `Engine.*`, `T()`), כך שמנוע
ההתאמה מבוסס-החוקים ניתן להחלפה עתידית במודל המלצות בלי לגעת ב-UI או במשחק.

## מבנה מנוע ההתאמה (היברידי, מבוסס חוקים ומשקלים)

**אותות נקלטים** (`Learn.record`): קטגוריה, נכון/שגוי/דילוג, זמן תגובה, סוג משחקון.
**משוב מפורש** (`Learn.feedback`): אהבנו / פחות / עוד כאלה / קשה יותר / קל יותר / חסימת נושא.

**חוקי ההתאמה:**
| החלטה | חוק |
|---|---|
| רמת קושי | `diffScore` רציף 1–3 לכל משתתף; חלון 6+ תשובות: הצלחה ≥80% → ‎+0.25, ≤30% → ‎-0.25; משוב מפורש → ‎±0.5 |
| משקל קטגוריה | הצהרה מוקדמת ‎+0.5, לייקים/"עוד" מעלים, דילוגים/"פחות" מורידים, הצלחה תורמת מעט; נושא חסום → 0 |
| תמהיל ערבוב חכם | משקל בסיס 1 + דחיפה לסוגים ששוחקו ואהבו (עד ‎+1.5) |
| קאמבק | פער ≥2 (סיבוב קצר) / ≥3 — הצעה **גלויה** בהסכמת שניים, בלי שינוי חוקים בחשאי |
| ביטחון | `confidence = min(1, אותות/20)` — ניסוחי ה-UI כנים לפי הרמה ("רק מתחילים" → "מתחילים להבין" → "מכירים את הטעם שלכם") |

אין הסקה מתשובה אחת: כל החוקים דורשים צבירת אותות (חלון 6-8 או משוב מפורש).

## מבנה נתונים — פרופיל משתתף

```js
state.players.p1 = {
  name: "גיל",                 // בדיוק כפי שהוזן
  topics: "מכוניות, ספורט",    // הצהרה מוקדמת
  avoid: "",                    // נושאים רגישים אישיים
  humor: "שנון",               // סגנון הומור
  prefDiff: "varied",           // העדפת קושי מוצהרת
  model: {                      // נלמד בהדרגה
    categories: { "מוזיקה": { shown, correct, wrong, skipped, liked, disliked, more } },
    diffScore: 2.0,             // קושי רציף 1–3
    recent: [1,0,1,...],        // חלון הצלחות אחרון
    answerMsTotal, answers,     // זמן תגובה
    blockedTopics: [],          // נושאים שנחסמו במשוב
    typeUse: { head2head: 4 },  // אילו משחקונים שוחקו
    feedbackLog: [...],         // 30 משובים אחרונים
  }
}
```

## תבניות שפה — שימוש בשמות

מערכת משתנים מרכזית (`T(template, buildCtx())`):
`{{player_1_name}} {{player_2_name}} {{current_player_name}} {{other_player_name}} {{leading_player_name}} {{trailing_player_name}} {{driver_name}} {{score_difference}}`

דוגמאות מהמערכת:
- "{{driver_name}} על ההגה 🚗 — עיניים לכביש!"
- "{{leading_player_name}} מוביל/ה כרגע, אבל {{trailing_player_name}} כבר חימם/ה מנועים."
- "אתגר קאמבק! {{trailing_player_name}} מאחור ב-{{score_difference}} — אם שניכם מסכימים..."
- "{{current_player_name}}, זאת בדיוק השאלה שיכולה להפוך יתרון קטן לנאום ניצחון מוגזם."
- כפתורי ניקוד: "גיל קרוב יותר ✅" / כותרות תור: "🎯 התור של אניה"

אין בשום מקום "בן הזוג" / "הפרטנר" / "שחקן 1" — נבדק אוטומטית.

## 36 קטעי המעבר

בקובץ `js/templates.js` — 9 סוגים: מצב-משחק (יתרון/צמוד), שדר ספורט, עובדות
מאומתות, הומור, טיפים זוגיים, טיזרים, מחמאות, בזק/סקר, מטא. בחירה עם אנטי-חזרה
(12 אחרונים + לא אותו סוג פעמיים ברצף), תנאי ניקוד, ותדירות לבחירה (מעט/מאוזן/הרבה).

## מגבלות ידועות

1. **קריאות Claude API לא נבדקו מול מפתח אמיתי** בסביבת הפיתוח (חסימת רשת) — הקוד נבנה לפי מפרט ה-API הרשמי ונדרש סבב אימות אחד עם מפתח.
2. **התאמת קושי במאגר המובנה חלקית** — לשאלות הבנק אין תגית קושי מלאה; הקושי הנלמד משפיע בעיקר על שאלות ה-AI (שמקבלות שדה difficulty).
3. **הקראת שמות** תלויה בקול he-IL של המכשיר; תיקון הגייה נעשה דרך כתיב פונטי בפרופיל (אין שדה הקראה נפרד).
4. **למידת קטעי מעבר** — נמדד שימוש בלבד; אין עדיין דירוג קטעים ("איזה סגנון הצחיק").
5. **זיהוי דמיון סמנטי** בין שאלות AI — הבדיקה טקסטואלית (מזהה + רשימת אחרונות בפרומפט), לא embedding.
6. **מצב "מותאם לזמן נסיעה"** מיוצג על ידי בורר אורך ידני (קצר/בינוני/ארוך), לא לפי ETA מהניווט.

## המלצות לשלב הבא

1. סבב QA עם מפתח API אמיתי: יצירה + אסמכתאות + prefetch בנסיעה אמיתית.
2. תגיות קושי מלאות למאגר המובנה, וסינון לפי diffScore גם בו.
3. דירוג קטעי מעבר (👍 קטן על הקטע) → למידת סגנון הומור בפועל.
4. קלט קולי (Web Speech Recognition) לתשובות — היום הקול הוא פלט בלבד.
5. שכבת סנכרון אופציונלית (חשבון/ענן) אם תרצו לשחק מכמה מכשירים — היום הכול מקומי.
6. החלפת מנוע המשקלים במודל המלצות קטן כשיצטברו נתונים (הממשק `Learn.*` כבר מוכן לכך).
